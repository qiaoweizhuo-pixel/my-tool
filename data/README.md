## Data Preparation

### Example Data
This repository includes a **minimal working example dataset**  consisting of **50 representative sequences from P450 families**. This dataset is **NOT** the actual data used in the study, but is designed to:

1.  Verify that all scripts can execute without errors
2.  Demonstrate the required input file formats
3.  Allow users to understand the analysis pipeline structure

### Access to Research Data
The **complete dataset** used in the published study is available through the following channels:

- **Processed feature matrices and analysis results**: The actual dataset is currently under embargo/submission to [数据库名称] under accession [编号]. It will be made publicly available upon manuscript acceptance. 
- **Original protein sequences and annotations**: Available upon reasonable request from the corresponding author under a **Data Use Agreement** (see below)

### Data Use Agreement (DUA)
Due to the potential for further development and application of these sequences, access to the full dataset requires:
1.  A formal request to the corresponding author (qiaozhu@gxyyzwy.com)
2.  Completion of a Data Use Agreement specifying:
    - Use limited to academic, non-commercial research
    - Proper acknowledgment in any resulting publications
    - Restrictions on redistribution
    - Duration of access (typically 1-2 years)
3.  Allow 2-4 weeks for request processing
